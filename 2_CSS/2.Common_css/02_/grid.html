CSS Grid — Quick Notes

This page contains essential CSS Grid concepts used in modern frontend development.

1. Enable Grid

display: grid;

2. Define Columns & Rows

grid-template-columns: 1fr 1fr;        /* Two equal columns */
grid-template-rows: auto auto;        /* Two rows */

3. Helpful Functions

repeat()

grid-template-columns: repeat(3, 1fr);

minmax()

grid-template-columns: minmax(200px, 1fr);

auto-fit / auto-fill

grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

4. Gap (Spacing)

gap: 16px;

5. Placing Items

Span columns/rows

grid-column: span 2;
grid-row: span 1;

Position by line numbers

grid-column: 1 / 3;
grid-row: 2 / 3;

6. Align Items

place-items: center;        /* align + justify */

7. Auto Placement

grid-auto-flow: row;        /* default */
grid-auto-flow: column;
grid-auto-flow: dense;

8. Grid Template Areas (optional but useful)

grid-template-areas:
  "header"
  "main"
  "footer";

End

These are the most commonly used Grid features in real projects.
