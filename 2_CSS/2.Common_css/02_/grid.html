CSS Grid Complete Notes on One Page

Use this page as a complete reference for CSS Grid properties, functions, and utilities.

1. Turn an element into a Grid Container

display: grid;
display: inline-grid;

2. Grid Template Definitions

Rows & Columns

grid-template-columns: 200px 200px;
grid-template-rows: 100px auto;

repeat() function

grid-template-columns: repeat(3, 1fr);

minmax() function

grid-template-columns: repeat(3, minmax(150px, 1fr));

auto-fit & auto-fill

grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));

Grid Template Areas

grid-template-areas:
  "header header"
  "sidebar main"
  "footer footer";

3. Gutters (Spacing)

gap: 20px;
row-gap: 10px;
column-gap: 15px;

4. Item Positioning

Placing Items by Line Numbers

grid-column: 1 / 3;
grid-row: 2 / 4;

Shortcut

grid-area: row-start / col-start / row-end / col-end;

Span keyword

grid-column: span 2;
grid-row: span 3;

Item alignment

justify-self: start | end | center | stretch;
align-self: start | end | center | stretch;
place-self: align-self justify-self;

5. Container Alignment

justify-items: start | end | center | stretch;
align-items: start | end | center | stretch;
place-items: align-items justify-items;

justify-content: start | end | center | space-between | space-around | space-evenly;
align-content: start | end | center | space-between | space-around | space-evenly;
place-content: align-content justify-content;

6. Auto-placement Properties

grid-auto-rows: 100px;
grid-auto-columns: 200px;
grid-auto-flow: row | column | dense | row dense | column dense;

7. Shorthand: grid

grid: auto-flow dense 100px / repeat(3, 1fr);

8. Named Lines

grid-template-columns:
  [left] 1fr [center] 2fr [right] 1fr;

Using named lines

grid-column: left / right;

9. Subgrid (Only in modern browsers)

grid-template-columns: subgrid;
grid-template-rows: subgrid;

10. Useful Debugging Tip

Apply this to visualize grid lines:

* {
  outline: 1px solid rgba(0,0,0,0.2);
}

End of Notes
